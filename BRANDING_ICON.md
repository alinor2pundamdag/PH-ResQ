# PH-ResQ Launcher Icon

The launcher emblem is cropped from the user's supplied PH-ResQ badge image. Only the circular medallion is retained; the surrounding blurred photograph is excluded and the outside of the round badge is transparent.

- Source of truth: supplied circular PH-ResQ emblem.
- Legacy launcher icon: `mipmap-xxxhdpi/ic_launcher.png` and `ic_launcher_round.png`.
- Adaptive icon: `mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml`.
- Adaptive foreground uses a 17% inset so the complete circular rim remains inside Android's adaptive-icon safe zone.
- Background: existing dark navy brand color.
- Monochrome themed icon: existing monochrome vector retained until a dedicated monochrome brand mark is approved.

Do not add the original photo background to the app icon. Preview on Android launcher masks and themed-icon mode before release.
