# PH-ResQ
Isang offline emergency app para sa Pilipino na may galaw na watawat. Gamit ang GPS, kusang lumalabas ang pinakamalapit na pulis, bumbero at ospital kahit walang internet. Paalala: Mangangailangan ng regular call o text load para sa direktang pagtawag at pagpapadala ng SOS emergency SMS sa mga otoridad tuwing may sakuna.
